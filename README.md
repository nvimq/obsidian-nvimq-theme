# 🖥️ nvimq — Obsidian Theme

> Чёрно-белый металлический минимализм с фиолетовым акцентом и прозрачностью.
> Вдохновлён эстетикой Ghostty терминала.

![Dark theme](screenshot-dark.png)
![Light theme](screenshot-light.png)

## Особенности

- ⚫ **Монохромная основа** — глубокий чёрный и металлический серый
- 🟣 **Фиолетовый акцент** — тонкий, не навязчивый
- 🪟 **Прозрачность с размытием** — Translucency + backdrop-blur
- 🔤 **JetBrains Mono** — во всём интерфейсе
- 🌙 **Тёмная тема** — угольно-чёрная с металлическим отливом
- ☀️ **Светлая тема** — слоновая кость с металлическим серым
- 📦 **Минимализм** — никаких лишних рамок и границ
- ⚡ **Ghostty-стиль** — тонкие скроллбары, чистые вкладки, плавные анимации

## Установка

### Через Obsidian Themes Browser
1. Открой **Settings → Appearance → Themes**
2. Нажми **Browse** и найди `nvimq`
3. Нажми **Install** и **Use**

### Вручную
1. Скачай архив с [GitHub](https://github.com/nvimq/obsidian-nvimq-theme)
2. Распакуй в `.obsidian/themes/obsidian-nvimq-theme/`
3. Выбери тему в **Settings → Appearance → Themes**

## Рекомендуемые настройки

Включи **Translucency** (`Settings → Appearance → Translucency`)  
Установи шрифт **JetBrains Mono** в настройках внешнего вида.

## Настройка через Style Settings

Если установлен плагин **Style Settings**, можно менять:
- Акцентный цвет
- Силу размытия
- Сильное размытие (модальные окна)

## Цветовая схема

| Роль | Тёмная | Светлая |
| :--- | :--- | :--- |
| Фон | `#000000` (80% прозрачности) | `#f5f5f0` (80% прозрачности) |
| Текст | `#e0e0e8` | `#1a1a1a` |
| Акцент | `#bd93f9` | `#8b6ccf` |
| Металл | `#8a8a8a` | `#a0a09a` |
